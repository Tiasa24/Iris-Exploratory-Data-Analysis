# Iris Exploratory Data Analysis

Exploratory data analysis of the **Iris flower dataset** using Python to identify patterns, relationships and statistical differences between three flower species.

### Key Features

* Analysed **150 flower samples** across Setosa, Versicolor and Virginica
* Explored feature distributions using **histograms and statistical measures**
* Investigated relationships between petal and sepal measurements using **scatter plots**
* Performed **correlation analysis** using a heatmap to identify relationships between variables
* Identified **petal length and petal width** as strong indicators for distinguishing species

**Tech:** Python · Pandas · NumPy · SciPy · Matplotlib · Seaborn
